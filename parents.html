Byte Belts Grown-ups

Grown-ups guide

Byte Belts is a free, belt-based coding course you run at home. Children earn belts by passing a Belt Test for each big idea, moving from tap-the-arrow puzzles, to Scratch-style blocks, to typing real Java.

How to run a session

  1. Warm up away from the screen (5 min). Each lesson plan starts with an "unplugged" game that teaches the idea with bodies and paper.
  2. Play 2–4 levels (10–20 min). Sit beside your child. They hold the mouse or tablet; you ask questions.
  3. Talk it over (2 min). Ask one of the plan's questions: what did the program do, and why?

The golden rule: when something goes wrong, do not fix it for them. Ask "what did you expect to happen?" and "where did it go differently?" Finding the bug is the lesson.

Stars and belts

  • Every solved level earns 1–3 stars. Three stars means the answer was as short as the model answer — it rewards using loops and functions.
  • The last level in each belt is the Belt Test. Passing it without help, and explaining the answer aloud, earns the belt.
  • Some levels have a rule (for example "use a loop"), and some change every time Run is pressed, so the code has to work in general.
